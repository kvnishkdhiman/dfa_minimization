Project Overview: DFA-Min

DFA-Min is a web-based educational simulation lab designed for Automata Theory and Computability courses. It demystifies Deterministic Finite Automata (DFA) minimization by visually demonstrating the Partition Refinement Algorithm (Hopcroft / Moore), generating shortest distinguishing strings for non-equivalent states, and providing formal product-automaton language equivalence verification.

Three-Layer System Architecture

[Frontend Presentation Layer]
• Cytoscape.js Graph Engine (Canvas, layouts, physics, dynamic animations)
• Partition Refinement Stepper UI (P₀ to P_final with signature inspection)
• Interactive Transition Matrix & String Tester

[Backend Computation Layer (Python & Flask)]
• DFA Validation Engine (Determinism, alphabet coverage, completeness)
• Reachability Module (BFS from initial state q₀)
• Partition Refinement Engine (Signature-based splitting & step history)
• Distinguishing String Finder (BFS state-pair cross-product)
• Language Equivalence Checker (Synchronous product automaton verification)

[Data Model & Exchange Layer]
• Formal 5-tuple JSON representation: M = (Q, Σ, δ, q₀, F)
